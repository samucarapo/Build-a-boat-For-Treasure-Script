# Features

Automation

Auto Farm Gold

- Automatically follows a predefined farming route.
- Moves through multiple CFrame positions.
- Uses smooth movement between locations.
- Waits at the final position before repeating the route.
- Automatically enables noclip while farming.
- Restores the player's original position when the farm is stopped.

Auto Open Chest

- Automatically opens chests at a configurable interval.
- Supports Common, Uncommon, Rare, Epic, and Legendary Chests.
- The chest type can be changed directly from the UI.

Team Teleports

One-click teleports to:

- Red Team
- Black Team
- Blue Team
- Purple Team
- Yellow Team
- Green Team
- White Team

Utilities

Anti Water

- Disables touch interaction with objects named "Water" or "WaterPart".
- Can be toggled on and off.

Anti-AFK

- Prevents the player from being marked as AFK.
- Enabled by default.
- Can be toggled from the UI.

Movement Settings

Custom WalkSpeed

- Change WalkSpeed from "0" to "500".
- The selected value is continuously maintained.

Custom JumpPower

- Change JumpPower from "0" to "500".
- The selected value is continuously maintained.

- Roblox
- Build a Boat for Treasure

# Installation

1. Join Build a Boat for Treasure.
2. Execute the loadstring above.
3. Click the "SHADOW" button to open the interface.
4. Enable the features you want to use.
